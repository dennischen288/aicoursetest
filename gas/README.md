# 炙餃線上訂單 × Google 試算表

網站結帳 → Google Apps Script（GAS）→ 寫入試算表「鍋貼店預約」。

```
顧客按「送出訂單」
   │  POST JSON（text/plain，避免 CORS 預檢）
   ▼
GAS 網頁應用程式 doPost()
   ├─ 驗證欄位、以「商品」工作表重新計價（不信任前端金額）
   ├─ 依 requestId 防止重複建單（逾時重送不會多一筆）
   ├─ 寫入「訂單」工作表，狀態「待確認」
   └─ （選用）寄 Email 通知店家
   │
   ▼  回傳 { ok, orderId, total }
網站顯示訂單編號
```

## 一、安裝 GAS（約 5 分鐘）

1. 打開試算表「鍋貼店預約」→ **擴充功能 → Apps Script**。
2. 把 `Code.gs` 的全部內容貼進編輯器的 `程式碼.gs`（取代原內容），儲存。
3. （選用）左側「專案設定」勾選「在編輯器中顯示 appsscript.json」，貼上本資料夾的 `appsscript.json`。
4. 上方函式選單選 `setup` → **執行**，依提示授權（會看到「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」，這是你自己的程式）。
5. 回到試算表重新整理，會出現：
   - **訂單** 工作表（原本的空白工作表會改名）
   - **商品** 工作表（價格與網站一致）
   - 上方選單 **🥟 炙餃訂單**

## 二、部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按「部署」，複製結尾是 `/exec` 的網址。
4. 把網址貼到網站的 `checkout-config.js`：

   ```js
   window.ZHIJIAO_CHECKOUT_CONFIG = Object.freeze({
     endpoint: 'https://script.google.com/macros/s/XXXX/exec'
   });
   ```

   `endpoint` 留空時，網站維持「示範模式」，不會送出任何資料。

> 之後修改 `Code.gs`，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不會改變。若改用「新增部署作業」會產生新網址，需要再更新 `checkout-config.js`。

## 三、日常使用

| 功能 | 操作 |
|---|---|
| 處理訂單 | 在「訂單」C 欄下拉切換：待確認 → 已確認 → 製作中 → 可取餐 → 已完成／已取消（會自動上色） |
| 今日營業額 | 選單 🥟 炙餃訂單 → 今日訂單統計 |
| 新訂單 Email 通知 | 選單 → 設定新訂單通知 Email |
| 暫停／恢復接單 | 選單 → 暫停接單／開始接單（暫停時網站會顯示提示，購物車保留） |
| 修改價格、下架 | 「商品」工作表修改單價或取消勾選「上架」 |

**改價格時，網站 `index.html` 的 `products` 也要同步修改。** 兩邊不一致時，系統會拒絕訂單並請顧客重新整理，不會以錯誤金額成立訂單。

## 四、安全與限制

- 試算表保持私人，只分享給處理訂單的人；網頁端點只能新增訂單，不能讀取資料。
- 價格以試算表為準；文字欄位會跳脫 `= + - @` 開頭，避免公式注入。
- 每分鐘最多 30 筆訂單（簡易防灌單），沒有驗證碼；若遭濫用可先「暫停接單」。
- 不處理線上付款，訂單成立後由店家聯絡確認。
- 送出的個資（姓名、電話、地址）會存在試算表中，正式上線前請更新網站的隱私權說明。
